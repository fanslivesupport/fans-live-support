Fans Live Support - SEO 文件上传说明

你需要上传的文件：
1. sitemap.xml
2. robots.txt

上传位置：
请把 sitemap.xml 和 robots.txt 上传到 GitHub 仓库的最外层目录，也就是和 index.html、english.html、bahasa.html 同一个位置。

正确的文件结构应该像这样：

fans-live-support/
├── index.html
├── english.html
├── bahasa.html
├── sitemap.xml
├── robots.txt
└── 其他图片 / CSS / JS 文件

上传后，请检查这两个链接是否能正常打开：

https://fanslivesupport.github.io/fans-live-support/sitemap.xml

https://fanslivesupport.github.io/fans-live-support/robots.txt

如果这两个链接能打开，说明上传位置正确。

下一步：
1. 打开 Google Search Console
2. 进入你的网站资源
3. 找到「站点地图 / Sitemaps」
4. 提交：

sitemap.xml

或者完整网址：

https://fanslivesupport.github.io/fans-live-support/sitemap.xml

然后分别用「网址检查」提交这三个页面：

https://fanslivesupport.github.io/fans-live-support/
https://fanslivesupport.github.io/fans-live-support/english.html
https://fanslivesupport.github.io/fans-live-support/bahasa.html

注意：
- 不要频繁删除和重新上传整个网站。
- 如果刚提交后显示还没有收录，不代表出错。
- GitHub Pages 新网站通常需要一点时间让 Google 重新抓取。
- 中文页先收录，英文和马来文晚一点收录是正常情况。
- 上传 sitemap.xml 和 robots.txt 后，等 Google 重新抓取即可。
